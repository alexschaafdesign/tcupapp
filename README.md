# TCUPBOARD

v2.0 in progress.

- Utilizes [biome](https://biomejs.dev) for linting and formatting.
- Managed with [pnpm](https://pnpm.io) and [pnpm workspaces](https://pnpm.io/workspaces).

### Apps
- **Frontend** - A React client application that serves the tCUPBOARD UI.
- **Backend** - An Express.js web server and suite of scrapers.
